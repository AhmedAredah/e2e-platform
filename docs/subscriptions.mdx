Use an existing subscription without a separate API key. Choose your plan
in `e2e-cpp init`, install dependencies, then sign in:

| Subscription | Command |
| --- | --- |
| ChatGPT Plus or Pro | `npx --no-install e2e-cpp login openai` |
| GitHub Copilot | `npx --no-install e2e-cpp login github-copilot` |
| SuperGrok or X Premium+ | `npx --no-install e2e-cpp login spacexai` |

Follow the terminal prompts, then run `npx --no-install e2e-cpp run`. Agent calls use your
plan's usage limits. For a new project, start with the [quickstart](/quickstart).

Claude subscriptions are not supported. To use Claude, configure an
[API provider](/models) or a model available through your Copilot plan.

## Set up an existing project

`e2e-cpp init` leaves existing configs intact. To switch an existing project to
a subscription, install its packages and replace the model in your config.
The `/path/to/` examples below refer to your locally packed OAuth module; this
source archive does not publish the fork packages:

<Tabs>
  <Tab title="ChatGPT">
```bash
npm install -D ai /path/to/e2e-cpp-oauth-0.1.0.tgz @ai-sdk/openai
npx --no-install e2e-cpp login openai
```

```ts title="Model setup"
import { createAgent } from '@e2e-cpp/core/agent';
import { chatgpt } from '@e2e-cpp/oauth/chatgpt';

const agent = createAgent({ model: chatgpt('gpt-5.5') });
```
  </Tab>
  <Tab title="GitHub Copilot">
```bash
npm install -D ai /path/to/e2e-cpp-oauth-0.1.0.tgz @ai-sdk/openai-compatible
npx --no-install e2e-cpp login github-copilot
```

```ts title="Model setup"
import { createAgent } from '@e2e-cpp/core/agent';
import { copilot } from '@e2e-cpp/oauth/copilot';

const agent = createAgent({ model: copilot('claude-sonnet-5') });
```
  </Tab>
  <Tab title="SuperGrok">
```bash
npm install -D ai /path/to/e2e-cpp-oauth-0.1.0.tgz @ai-sdk/xai
npx --no-install e2e-cpp login spacexai
```

```ts title="Model setup"
import { createAgent } from '@e2e-cpp/core/agent';
import { grok } from '@e2e-cpp/oauth/grok';

const agent = createAgent({ model: grok('grok-4') });
```
  </Tab>
</Tabs>

Set `agents: { default: agent }` in `e2e.config.ts`. Choose a model
available to your account.

## Sign-in help

- ChatGPT opens a browser to sign in. Use `npx --no-install e2e-cpp login openai --device`
  to sign in with a device code instead.
- Copilot reuses your GitHub CLI login. If you do not use `gh`, pass
  `--client-id` for your own GitHub OAuth app with device flow enabled.
  Use `--enterprise-url` for GitHub Enterprise.
- SuperGrok prints a device code and the URL where you enter it.

Run `npx --no-install e2e-cpp login` to choose a provider and see which accounts are signed
in. Run `npx --no-install e2e-cpp logout` to remove a saved login.

## Saved credentials and CI

Logins are stored in `~/.config/e2e-cpp/oauth.json`, or under
`$XDG_CONFIG_HOME`, with file permissions restricted to your user. Tokens
refresh automatically.

Use API keys in CI. `E2E_OAUTH_CREDENTIALS` can supply credential JSON
instead of the local file, but refreshed tokens are not saved back to that
variable. A value containing a rotating refresh token cannot be reused
indefinitely. See [CLI reference](/reference/cli#e2e-login) for all sign-in
options.

## Cancellation and diagnostics

OAuth token exchanges, refreshes and individual device requests have a
30-second deadline that includes reading the response body. Device polls also
stop at the code's expiry. A cancelled model call stops waiting immediately;
other calls can still complete a shared refresh. A custom OAuth provider receives
an optional signal in `refresh(credentials, signal)` and should honor it.
Embedders using `createOAuthFetch` can set `refreshTimeoutMs`.

Error responses are bounded to 64 KiB. Diagnostic messages remove submitted
grant values and control characters and are capped at 512 characters. Unknown
or transformed secrets in arbitrary output cannot be inferred.
